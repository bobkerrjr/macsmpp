# macsmpp

Gateway SMPP pessoal ([bobkerrjr/macsmpp](https://github.com/bobkerrjr/macsmpp)).

O código atual é um codec C++ de PDUs SMPP 3.3 / 3.4 / 5.0 com um harness Xcode. A sessão TCP do gateway ainda não está implementada.
